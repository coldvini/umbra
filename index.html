First launch: Umbra isn't notarized by Apple, so macOS blocks it once. Drag it into Applications, open it, then go to System Settings → Privacy & Security → Open Anyway. (Or run xattr -cr /Applications/Umbra.app in Terminal.) After that it updates itself — no need to come back here.

What you get

A full Windows runtime on your Mac, set up for you on first launch.

What runs

Umbra runs Windows software through Wine. Most things work — here's the honest picture.

Works well

Most DirectX 9–11 games, indie and older titles, launchers and everyday Windows utilities.

Depends

DirectX 12 games need D3DMetal — install Whisky or Apple's Game Porting Toolkit, then pick its engine.

Won't work

Games with kernel-level anti-cheat (Valorant and many competitive shooters).
